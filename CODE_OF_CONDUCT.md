# Code of Conduct

World Makers contributors are expected to maintain a professional, respectful, inclusive, and child-safety-first working environment.

Harassment, discriminatory conduct, sexualized behavior, threats, deliberate humiliation, or retaliation are not acceptable in project spaces. Product discussions involving children must use age-appropriate, privacy-preserving language and must not expose real child data in issues, screenshots, test fixtures, recordings, or logs.

Report conduct concerns privately to the repository owner or the designated project lead. Security vulnerabilities should follow `SECURITY.md` instead of public issue reporting.
