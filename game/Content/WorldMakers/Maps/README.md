# World Makers authored maps

This directory is reserved for Unreal-authored `.umap` assets.

The first required production level is:

`WM_PrototypeCertification.umap`

Canonical package path:

`/Game/WorldMakers/Maps/WM_PrototypeCertification`

Do not create placeholder text files with a `.umap` extension. Run `WorldMakers-G2-Author.cmd` on the locked Unreal Engine 5.8.2 workstation so Unreal creates the binary level, review it in the editor, and commit it through Git LFS.

Source-level G2 tooling may be complete while this binary is absent. In that state G2 remains **SOURCE READY / NATIVE AUTHORSHIP REQUIRED**, not certified.
